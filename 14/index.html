          수업용 식품영양 API 및 앱 가이드
        

        
      

      

        
• API 중계 주소: Netlify 서버(glittery-dasik-3cb269.netlify.app)를 통해 처리됩니다.

        
• 인증키 보안: serviceKey는 서버에서 자동 처리되므로 전송하지 않습니다.

        
• 누락값 처리: 영양 정보가 누락된 경우 [정보 없음]으로 표시되며, 0으로 자동 변환하지 않습니다. 누락값이 포함된 합계는 (확인된 값만 합산)으로 표기됩니다.

        
• 1회 분량 기준: 식단 추가 1회는 제공된 기준량(1회 분량) 기준입니다.

        
• CORS 안내: 통신 및 CORS 문제가 발생할 경우 사용자에게 친절하게 안내하며 가상 성공 데이터로 대체하지 않습니다.
